===== PAGINA 6 =====
03 Compatibilidad Windows 10
CONTEXTO IMPORTANTE
Windows 10 llegó a su fin de soporte el 14 de octubre de 2025. A junio de 2026 ya no
recibe parches de seguridad. Elfie Desktop puede desarrollarse y correrse en Windows 10,
pero hay consideraciones que vale tener presentes.
Qué funciona igual en Windows 10
Tauri 2.x + WebView2
Compatible. En Windows 10 WebView2 no
siempre está preinstalado, pero Tauri puede
empaquetarlo automáticamente con 
webview2InstallMode =
"embedBootstrapper" en tauri.conf.json.
Transparente para el usuario.
Ollama + Whisper + Kokoro
Todos soportan Windows 10 oficialmente. No
dependen de APIs del SO — corren sobre CUDA
y DirectX disponibles en Win10.
Auto-start · Tray · Shortcuts
Registro de Windows (auto-start), tray icon y
global shortcuts funcionan exactamente igual en
Windows 10 y 11.
Notificaciones nativas
Toast Notifications disponibles desde Windows
10 1809+. Tauri las usa por defecto sin
configuración adicional.
Rutas y LAUNCHERS existentes
Las rutas en actions.js ( C:/Users/
Sylft/...) ya son rutas de Windows. Sin
cambio al migrar el launcher a Tauri.
Picovoice Porcupine
SDK disponible para Windows 10. Requiere
Visual C++ Redistributable (normalmente ya
instalado).
Puntos a verificar antes de comprometerse
Drivers RTX 5060 en Win10
La RTX 5060 (Blackwell, 2025) es posterior al
EOL de Win10. NVIDIA generalmente mantiene
soporte de drivers, pero verificar que los drivers
actuales de la tarjeta soporten CUDA en
Windows 10 antes de asumir que Ollama/
Whisper funcionan con GPU.
Seguridad — SO sin parches
Elfie Desktop maneja tokens de Supabase y
OAuth de Google. Sin actualizaciones de
seguridad del SO desde octubre 2025, existe
riesgo real. Recomendable migrar a Windows 11
antes o durante Fase 4 (IA local).
RECOMENDACIÓN
Desarrollar normalmente en Windows 10. El código no cambia entre versiones de
Windows. Verificar drivers de la RTX 5060 antes de la Fase 3 (voz local). Planificar

AHORRO ESTIMADO CON IA LOCAL
PRTS web gasta Anthropic API en: clasificación inbox (~5 llamadas/día) + comandos de voz
(~10/día) + briefing (1/día). Con Ollama local, las clasificaciones y comandos simples
cuestan $0. Reducción estimada: 70–80% del gasto mensual. Solo briefings e insights
quedan en Claude API por calidad de contexto amplio.

===== PAGINA 17 =====
10 Mejoras Técnicas Internas
RAG Local con LanceDB
QUÉ RESUELVE
El módulo Apuntes de PRTS tiene notas por materia con 5 campos (conceptos, fórmulas,
dudas, conexiones, resumen). Hoy solo se puede buscar por texto exacto. Con RAG, Elfie
puede responder preguntas semánticas: "¿Qué anotamos sobre complejidad algorítmica?"
aunque no uses esas palabras exactas.
ALCANCE CLARO
Para qué sirve el RAG en PRTS: exclusivamente para el módulo Apuntes — el resto de los
módulos ya son datos estructurados en Supabase que el LLM puede consultar directamente con
SQL. RAG no aporta nada que una query SQL no haga mejor para tareas, gym o finanzas.
IMPLEMENTACIÓN
// Flujo RAG para Apuntes (LanceDB local)// 1. Al crear/editar una nota → generar embedding
const embedding = await ollama.embeddings({ model: 'nomic-embed-text', // modelo de
embeddings, ~270MB VRAM prompt: nota.conceptos + ' ' + nota.resumen }); // 2. Guardar en
LanceDB (elfie-desktop/db/apuntes.lance)await table.add([{ id: nota.id, materia:
nota.materia, vector: embedding.embedding, text: nota.resumen }]); // 3. Al preguntar por voz
→ buscar similares → prompt al LLMconst resultados = await
table.search(queryEmbedding).limit(3).execute(); const contexto = resultados.map(r =>
r.text).join(' '); // → LLM recibe contexto + pregunta → responde basado en TUS notas
LanceDB es un vector store embebido (como SQLite pero para vectores). No requiere servidor ni
Docker. Los embeddings se generan con Ollama local (nomic-embed-text, ~270 MB VRAM) y
viven en disco. Privacidad total: tus notas nunca salen de la computadora.
CUÁNDO IMPLEMENTARLO
RAG tiene sentido cuando hay suficiente volumen de notas (20+ apuntes distintos).
Implementarlo en Fase 6 da tiempo para acumular contenido real y validar que el caso de
uso efectivamente ocurre en el uso diario.

===== PAGINA 18 =====
Sin atajos globales, para interactuar con Elfie tenés que cambiar de ventana y hacer clic en
la app. Eso destruye el propósito de un asistente de escritorio. Los atajos globales son la
